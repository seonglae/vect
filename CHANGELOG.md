# Changelog

Distribution-side release notes. Source-level changes mirror [seonglae/vect](https://github.com/seonglae/vect/blob/main/CHANGELOG.md).

## [0.2.0] - 2026-05-19

First public distribution release.

### Installers
- macOS aarch64 / x86_64 (`.dmg`)
- Linux x86_64 (`.deb`, `.AppImage`)
- Windows x86_64 (`.msi`, `.exe`)

### Notable
- Multi-agent session orchestration
- CRDT team mode
- JSON-Render engine (6 block types)
- Skill / context editor
- Workflow engine, task board, roadmap, audit timeline
- Custom theme builder, customizable keybindings
- list_claude_sessions perf fix (O(N×P) → O(N+P))
