# Project Instructions Example

This file lives at the root of a project Vect opens. The agent reads it on every session.

## Commands

```
pnpm dev
pnpm test
pnpm lint
```

## Rules

- Use TypeScript strict mode
- Tailwind for styling
- No `as` type casts
- Early returns over nested else

## Architecture

Brief description of where things live, key files, conventions.

## Don't

- Don't edit `dist/` or `node_modules/`
